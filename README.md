# Attack-Detection-Log-Analysis-


This project focuses on detecting malicious activities by analyzing system and network logs. It simulates real-world SOC operations where security analysts monitor logs, identify threats, and respond to suspicious behavior.
The project demonstrates practical skills in log analysis, threat detection, and incident investigation using industry-standard tools.

Objectives
Detect brute force attacks using authentication logs
Identify suspicious IP activity
Analyze system events for privilege escalation
Create detection rules and alerts
Perform basic incident investigation
